# Phantom World Discord Bot (ALL-IN-ONE)

Multipurpose Discord bot for **Phantom World** — 400+ slash commands, music, moderation, economy, tickets, and FiveM status bridge.

**Developed by Phantom World**

## Quick start

1. Copy `.env.example` to `.env` and set `DISCORD_BOT_TOKEN` + `MONGO_TOKEN` (MongoDB Atlas).
2. Merge `env.host` into `.env` for FiveM / Lavalink / guild IDs.
3. `npm install` then `npm start` (or `node index.js` on KataBump).

See [PHANTOM_AIO_SETUP.md](PHANTOM_AIO_SETUP.md) for KataBump upload and MongoDB setup.
