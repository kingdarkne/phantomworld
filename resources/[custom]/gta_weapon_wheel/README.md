# gta_weapon_wheel (bridge)

Enables the **native GTA weapon wheel** via ox_inventory (weapons seeded from inventory).

The previous custom NUI wheel was removed — it used `SetNuiFocus` and frequently unlocked the mouse / froze movement.

## Usage
- **Hold TAB** — GTA weapon wheel
- `/freemouse` — clear stuck mouse/UI focus

## Related
- Visual upgrade: `3dweaponwheel` ([gtasnail/3dweaponwheel](https://github.com/gtasnail/3dweaponwheel))
- Inventory sync: ox_inventory `weaponWheel(true)` + wheel selection → equip slot
