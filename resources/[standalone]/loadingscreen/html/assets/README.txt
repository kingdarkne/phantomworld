Loading screen music
====================

Place your loading screen music file here as:

  music.mp3

The fxmanifest already declares this file. If your loadingscreen UI was built
to play it, it will be available at the path html/assets/music.mp3 once you
add the file.

If the bundle does not auto-play it, you may need to add an <audio> element
in the loadingscreen HTML/JS that uses this path.
